Creature Player

Easily watch Kick, Vaughn with 1 second latency, Angelthump, Rumble and OK.RU streams, with the platform's chat! Automatically keeps track of the current conductor and available channels. Auto updates. More features are in development, stay tuned. Installation takes 30 seconds, very easy just follow the steps down below:

1

Install TamperMonkey

All you need is the tampermonkey userscript extension, it's available for every browser. I suppose you could use it with other userscript managers, but it hasn't been tested.

2

Enable Developer Mode & Allow Access to User Scripts

This step is only necessary for Chromium browsers (Chrome, Edge, Brave, Opera, etc.). If you are on Firefox, you can completely skip it.

Open a new tab and navigate to your browser's extensions page (e.g., chrome://extensions or edge://extensions). Then, follow the visual steps below to finish the setup:

Step A
Turn on the Developer Mode toggle switch in the top-right corner (Chrome) or somewhere in the extensions page for other browsers. This might not be necessary anymore, enable it just in case.
Step B
Click details on Tampermonkey extension and check Allow user scripts.. This is the important step to make sure the player actually works correctly!
3

Install the script

Just click the button below to install the creature player userscript directly into Tampermonkey, then head to tapa_tapa_mateo!
